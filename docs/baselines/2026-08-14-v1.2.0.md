## Product baseline

Rin v1.2 remains one Cloudflare-native serverless blog product:

- Cloudflare Pages is the sole frontend host.
- A narrow Pages Functions gateway forwards API, RSS, and favicon requests through the `RIN_API`
  service binding.
- A backend-only Worker owns application APIs, scheduled jobs, and queue consumers and is not
  exposed on `workers.dev`.
- D1 is authoritative for relational data and is the default cache store.
- R2 is the object store for public image assets; internal cache artifacts are not public.

Queues, cron triggers, and Workers AI remain optional Cloudflare capabilities. ShokaX is outside
this repository and remains unchanged.

## Sealed security boundary

- GitHub OAuth is the only login method.
- Only the numeric GitHub identity configured in `RIN_GITHUB_ADMIN_ID` may create a session or
  enter the administration area.
- Password login is removed, and the legacy login endpoint always returns `403`.
- Migration `0012` clears legacy password hashes and adds per-user session versions.
- Pull requests build and test but cannot deploy production or a privileged preview.
- Production deployment uses trusted default-branch source rather than pull-request artifacts.
- Preview Worker, D1, R2, queue, and external-storage configuration are isolated from production.
