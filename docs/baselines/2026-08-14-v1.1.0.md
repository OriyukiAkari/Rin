# Rin v1.1.0 baseline archive

- Archive date: 2026-08-14
- Commit: `bdd18cd`
- Release tag: `v1.1.0`
- Immutable archive tag: `rin-baseline-v1.1.0-20260814`
- Successor line: `v1.2-security`

This archive preserves the repaired v1.1 architecture before v1.2 security work. The baseline is
a modern serverless blog on the Cloudflare developer platform: Cloudflare Pages hosts the public
site and its narrow Functions gateway, a private Worker provides backend functions, D1 provides
SQLite-compatible persistence, and R2 provides object storage.

ShokaX is outside the v1.2 security scope and remains unchanged.
