## Product baseline

Rin is a modern serverless blog system built on the Cloudflare developer platform:

- Cloudflare Pages hosts the web frontend;
- Cloudflare Workers provides serverless backend functions;
- Cloudflare D1 is the SQLite database;
- Cloudflare R2 is the primary object store.

The v1.1 line may simplify boundaries and deployment around this product definition, but it
must not collapse the frontend back into Worker Assets or replace D1/R2 with a second primary
data plane.

## Sealed v1.0 scope

The baseline includes the v1.0 authentication, request-origin, upload, comment moderation,
data-integrity, migration, cache, RSS, content-sanitization, and deployment hardening recorded
in `docs/v1.0-hardening.md` and `CHANGELOG.md`.

ShokaX is intentionally outside this repository and outside the v1.1 scope.
